# Internship Management System — Faculty Application

## Overview

The Faculty Application is a web application designed to help faculty administrators manage students, participating companies, and internship activities.

It provides centralized administrative tools for overseeing internship opportunities and monitoring students' progress throughout their practical training.

## Features

- **Faculty Authentication:** Provides secure access to authorized faculty users.
- **Company Management:** Supports viewing and managing company accounts, registering new companies, creating company login accounts, and activating or deactivating access.
- **Internship Overview:** Provides an overview of internship opportunities published by participating companies.
- **Student Management:** Supports creating, viewing, updating, and deleting student records.
- **CSV Import:** Enables importing student data from CSV files.
- **Student Progress Monitoring:** Allows faculty administrators to review student work diaries and monitor internship activities.
- **Company Feedback:** Provides access to feedback submitted by companies about students' internship performance.
- **Student Evaluation:** Supports evaluating students based on their practical work and received feedback.

## Technology Stack

- Java
- JSP-based web application
- Backend integration: Spring Boot REST API
- Database: Shared system database, accessed through the backend

## Integration

The Faculty Application communicates with the central backend to retrieve and manage student, company, and internship data. This integration keeps the information consistent across all applications in the system.

## Getting Started

1. Clone the repository.
2. Configure the application server and required project dependencies.
3. Configure the backend API connection.
4. Set up the required application configuration.
5. Build and deploy the application according to the project's server configuration.

## Project Context

This application is part of an Internship Management System developed as an Internet Programming university project at the Faculty of Electrical Engineering, University of Banja Luka.
